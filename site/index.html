Privacidade sem letra miúda

O essencial fica com você.

O Fala Comigo foi desenhado com uma regra simples: a comunicação básica deve funcionar localmente, sem internet, conta ou plano pago.

  • Dados e cartões personalizados ficam no dispositivo.
  • Não há anúncios nem venda de dados.
  • Compartilhamentos acontecem somente por ação do responsável.
  • O apagamento local remove os dados do aplicativo.

Perguntas frequentes

Clareza para escolher com tranquilidade.

Reunimos as respostas mais importantes sobre o aplicativo e sobre a forma como ele foi pensado.

O aplicativo funciona sem internet?

O núcleo foi projetado para uso local sem conta, mas ainda aguarda validação em aparelhos reais. Na prévia Web, recursos de mídia personalizada e notificações não têm paridade com o app nativo.

O Fala Comigo envia os dados da criança?

O código atual não implementa envio automático a um backend. A prévia Web pode gravar dados no armazenamento do navegador, cuja segurança e apagamento não foram validados para dados sensíveis. Use apenas dados sintéticos; exportações e compartilhamentos escolhidos pelo responsável saem do controle do app.

Preciso pagar para usar a comunicação básica?

O plano Essencial foi planejado como gratuito, mas ainda não há distribuição pública do app. Planos futuros são possibilidades, não serviços ativos.

O aplicativo substitui terapia ou diagnóstico?

Não. O Fala Comigo é uma ferramenta de apoio à comunicação e não substitui avaliação, terapia, orientação profissional ou decisões da família.

Como posso testar o aplicativo?

A prévia Web pode ser aberta pela opção “Abrir prévia Web”. O APK de validação para Android foi gerado, mas não foi testado em aparelho real nem distribuído em lojas. A versão Web não deve receber dados pessoais ou clínicos; use somente dados sintéticos.
