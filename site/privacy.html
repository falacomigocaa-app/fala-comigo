Privacidade e estado do produto

Última atualização: 30 de setembro de 2026.

Esta página descreve o estado atual do projeto e não substitui uma revisão jurídica. O Fala Comigo está em validação técnica; não há distribuição pública do app Android nem serviço conectado ativo.

Importante: use apenas dados sintéticos na prévia Web.

O armazenamento e o apagamento no navegador não foram validados para dados pessoais ou de saúde. Não informe nomes, diagnósticos, fotos, vídeos, gravações, frases ou registros de uma criança.

O que existe hoje

O código atual do app é voltado a uso local e não implementa envio automático de dados a um backend. Login de organização, portal conectado, sincronização remota, licenças administrativas e compartilhamento com clínicas ou escolas não estão ativos; páginas correspondentes no site são demonstrações estáticas com dados fictícios.

O site institucional é servido pelo GitHub Pages. O provedor de hospedagem pode processar dados técnicos de acesso conforme suas próprias políticas. O projeto não inclui anúncios ou scripts próprios de análise de audiência nesta página.

App Android/iOS e armazenamento local

O app nativo usa Hive para caixas locais e AES-GCM para novas mídias. A análise criptográfica das caixas, a migração de dados legados e a validação em aparelhos reais ainda são gates de lançamento. A abertura nativa cria um snapshot antes de Hive abrir uma caixa existente e restaura os bytes se a biblioteca tentar recuperá-la como vazia; migração automática de caixas antigas está desativada até haver um fluxo validado. Isso não é garantia de segurança para dados sensíveis nem confirmação de lançamento.

O responsável pode iniciar exportação ou compartilhamento pelo sistema operacional. Depois que um arquivo é entregue a outro app ou serviço, o Fala Comigo não controla cópias, retenção ou exclusão nesse destino. Não inclua contexto pessoal ao compartilhar, salvo se for estritamente necessário e o destinatário estiver confirmado.

Prévia Flutter Web

A prévia Web foi compilada, mas ainda não passou por revisão de segurança do armazenamento no navegador, teste de exclusão, acessibilidade completa ou validação em vários navegadores. A proteção do navegador não deve ser considerada equivalente à proteção nativa. Recursos de foto/vídeo personalizados, gravação e notificações não têm paridade funcional confirmada. A prévia serve para avaliação técnica com conteúdo inventado, não para uso clínico, escolar ou familiar com dados reais.

Dados locais do navegador podem permanecer em armazenamento do site até serem removidos pelos controles do navegador. A remoção pelo navegador não é uma garantia de apagamento seguro de cópias, backups, capturas ou conteúdo exportado.

Permissões, voz e compartilhamento

No app nativo, câmera, microfone e biblioteca de fotos são usados somente quando uma funcionalidade compatível é acionada. O funcionamento de voz, notificações, permissões e arquivos depende do sistema operacional e ainda requer validação em aparelhos reais. A versão Web não oferece atualmente uma promessa equivalente para esses recursos.

Apagamento

O app nativo inclui uma função para remover dados locais, mídias, credenciais e chaves. A rotina tenta cancelar notificações novamente; se o sistema não responder, o app informa que avisos genéricos podem continuar agendados. No navegador, o apagamento completo ainda não foi validado; não use a prévia Web para armazenar dados pessoais ou sensíveis. Em qualquer plataforma, arquivos já exportados para outro serviço não são apagados pelo app.

Sem portal conectado

Convites, tarefas, permissões, consentimentos, indicadores e planos institucionais exibidos em prévias são ilustrativos. Não há autenticação, banco conectado, autorização server-side ou isolamento de organizações implementados para uso real. Não envie dados de famílias por essas páginas.

Contato

Para dúvidas gerais, use falacomigocaa@gmail.com. Não envie por e-mail, WhatsApp ou issues públicas nomes, diagnósticos, fotos, vídeos, frases, registros ou outros dados pessoais de crianças. Um canal seguro para solicitações que envolvam dados ainda não está disponível.
